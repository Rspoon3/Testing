# Features

## Plinko Game
A physics-based Plinko game built with SpriteKit and SwiftUI. Players drop balls from the top of the board and watch them bounce off pegs before landing in scoring slots at the bottom.

### Features
- Realistic physics simulation using SpriteKit
- 10 rows of pegs in an alternating pattern
- 9 scoring slots with different point values (5, 10, 25, 50, 100)
- Score tracking with high score persistence per session
- 10 balls per game with visual ball counter
- Visual feedback when balls land in slots
- Reset/Play Again functionality
