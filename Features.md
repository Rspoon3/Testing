# Features

## Circle-to-Line Moon Phase Animation
A scroll-driven animation that transforms moon phases from a circular arrangement into a horizontal line. Inspired by the Stardust app, this animation provides a smooth transition based on scroll position, creating an engaging visual effect for displaying cyclical data.

**Components:**
- `MoonPhaseView`: Individual moon phase visualization with customizable fill and color
- `CircleToLineAnimationView`: Core animation logic that interpolates positions between circle and line layouts
- `MoonPhaseScrollDemoView`: Full demo implementation with scroll tracking
