# Features

## TV Episode Ranker

### TV Show Search
Search for TV shows using TMDB API. View show details including poster, description, and season count.

### Episode Ranking
Single-elimination tournament bracket to rank all episodes of a TV show. Side-by-side episode cards with scrollable content showing episode still, season/episode code, title, and description.

### Progress Tracking
Animated progress bar showing completion percentage during ranking sessions.

### Session Persistence
Save and resume ranking sessions using file-based JSON storage. Support for multiple concurrent sessions across different shows.

### Winner Display
Show the winning episode after completing all comparisons.
